## Suggested study order
1. Read `03_Lecture_Notes/` (overview).
2. Work through `01_Study_Guide/README.md` section by section, opening source materials in the matching topic folder for depth.
3. Take `02_Practice_Tests/PRACTICE_TEST_1.md`, then check `ANSWER_KEYS.md`.
4. Take `02_Practice_Tests/PRACTICE_TEST_2.md` (case-based) and review.
